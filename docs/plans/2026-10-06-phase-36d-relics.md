# Phase 36d: tier 4-6 gear, Legendary signatures and Set bonuses

Loot slice 5. Builds on [36a](2026-10-06-phase-36a-loot-item-model.md) (item
model), [36b](2026-10-06-phase-36b-gear-catalog.md) (catalog) and
[36c](2026-10-06-phase-36c-loot-economy.md) (economy).

## What ships

- **Tier 4 (Masterwork) and tier 5 (Runeforged) plain gear** for every
  weapon family, armor path, shield and offhand: items 10104-10185 (weapons),
  21000-21103 (armor) and 20310-20315 (shields). Drops only, never sold.
- **Tier 6 relics** (items 50001-50033, folder `relics-50000`): named,
  hand-made pieces. A *Legendary* has a signature (a gear effect that the
  rest of combat already reads) and two affixes; a *Set* piece has no
  affixes and counts toward a set bonus (`_datafiles/world/default/sets/`).
- **Gear effects** (`internal/classes/gear.go`): an allow-list of
  `classes.Effects` keys a relic may grant, each capped. The worn relics'
  effects are merged into `Character.ClassEffects()`, so battle, spells and
  company code read them with no new plumbing. Set bonuses count distinct
  worn pieces.
- **Boss drops** (`internal/loot/relics.go`): each relic names its boss and a
  percentage chance. One roll per kill per contributing company; bad-luck
  protection forces a relic on the 20th kill without one (count kept on the
  character, so it survives restart/copyover).
- **Player surfaces:** `help relics`, the inventory "Relics worn" panel, the
  GMCP `relic` / `relic_lore` fields and the gear window tooltip.

## Decisions

| Decision | Reason |
| --- | --- |
| Relics are not generated by the normal roll, but sell and salvage like any find | Owner ruling: treasure should pay (see Economy change below) |
| Plain tier 4+ pieces drop their salvage runestone when it is worth more than the piece | The 36c test: salvage must never yield more than the item's value |
| Gear effects are an allow-list with caps | A data file cannot invent a runaway number; the text builders only describe real effects |
| Relic ilvl = boss level + 5 | Relics sit above the zone's normal drops |
| Bad-luck count per boss on the leader's character | Persists with the company; no new store |
| Boss outside any drop profile still drops its relic | Relic bosses need not opt into zone profiles |

bases (the nearest-tier fallback draws tier 5); placing relic bosses in
zones is Phase 42's job.

## Economy change (owner, 2026-10-06 22:35)

The first build made relics unsellable and unsalvageable (no-profit rule).
Robinson then ruled that relics and rare drops may profit; treasure hunting
should pay. Changed: relics sell and salvage like any find; each relic file
carries a `value` (Legendary 500 + 25 per item level, Set 300 + 15 per item
level, so 705 to 1750 gold) and merchants still pay at most 25% of it. The
runestone trim stays so plain pieces never salvage for more than their value;
a relic's value exceeds its salvage yield. The no-profit rule still holds for
anything gathered or bought (food, herbs, cooked meals, shop goods).
