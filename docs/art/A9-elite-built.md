# A9: Elite classes in the game today

Read [00-standards.md](00-standards.md) first. For each elite, attach its
**parent advanced class's approved A8 sheets**. An elite is that class
made grander:

- a longer cape;
- a taller crest, hat or halo;
- richer trim;
- a stronger alignment cue.

It stays the same silhouette family and is clearly the same person, years
on.

Each elite needs **two files**:

- `art/source/A9/map/units/<id>.png`: a map figure sheet, 3 × 8.
- `art/source/A9/battle/units/<id>/idle.png`: a battle idle sheet, 1 × 4,
  size M, facing right.
