# A10: Planned elite classes

Read [00-standards.md](00-standards.md) first. These elites are named in
the game but **not playable yet**. Make each one only when the lead says
its class is being built. A class's look can still change before then,
so check its row with the lead first.

The rules are the same as [A9](A9-elite-built.md): attach the parent's
approved A8b sheets and make it grander, the same person years on. The
neutral lineages have no alignment trim, so grandeur comes from gear, crest
and bearing.

Each elite needs **two files**:

- `art/source/A10/map/units/<id>.png`: a map figure sheet, 3 × 8.
- `art/source/A10/battle/units/<id>/idle.png`: a battle idle sheet, 1 × 4,
  size M, facing right.
