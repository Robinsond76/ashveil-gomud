# Help for ~stat-train~

The ~stat-train~ command spends the Stat Points you earn as you level (see ~help progression~) to improve your character.

The shipped rules give one stat point every two levels (2, 4, 6, and so on). Regaining a lost level grants no extra points. Automatic stats also grow smoothly with level.

It will start an interactive prompt to choose what to improve in.

## Usage:

  ~stat-train~
